Class diagram for the controller base that enforces auth and tenant scoping for every request.

Purpose

Shows the class structure of ApplicationController: what it inherits, what callbacks it sets, and what it delegates auth/authorization to. Concrete controllers inherit from this and inherit the auth contract for free.

Decisions & Notes

  • Auth is not opt-in. Both before-actions are declared on the base; controllers that want to skip them must do so explicitly and that should be a code-review red flag.
  • Pundit at controller level. Authorization is enforced inside actions via authorize / policy_scope; missing an authorize call in a write action is a bug.
  • Errors handled centrally. Pundit / RecordNotFound errors translate to 403 / 404 through rescue_from at this layer.

Assumptions

  • The exact gem class name is shown for orientation; the actual class lives in the dopay-conductor gem.
  • Rescue handlers shown are illustrative; the codebase may include additional ones (e.g., parameter parsing errors).
